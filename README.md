# DSA, from First Principles

A standalone, hash-routed study guide for data structures and algorithms. It follows the same course shape as `../backend`: choose a track, move through ordered steps, and learn each idea through its problem, solution, limitation, and common pitfall.

Open `index.html` directly in a browser, or serve the directory locally:

```sh
python3 -m http.server 4179 --directory dsa
```

Then visit `http://localhost:4179/`.

## Tracks

1. Foundations — complexity, space, recursion, invariants, and constraints.
2. Core Data Structures — arrays through tries.
3. Advanced Data Structures — deques, search trees, range queries, caches, and probabilistic structures.
4. Algorithm Patterns — two pointers, windows, search, sorting, greedy, and more.
5. Graphs & Connectivity — traversals, shortest paths, dependencies, and spanning trees.
6. Dynamic Programming — state design, classic patterns, and optimization.
